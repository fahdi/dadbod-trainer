Session 1: Full Body

Sunday, July 26, 2026 · 30 min · First day back · Coached by Brian Andrews, founder of Define Fit

Fahad, 41 · local gym (cable machine, dumbbells, basics) · wrist injury from a 2020 mountain bike accident, neutral grip throughout · first workout in years, moderate intensity.

How to run it

Each round has 3 exercises (A, B, C). Do A, B, C in order, that's 1 set. Rest, then repeat the whole round. 3 times through, then move to the next round.

Rest: 45–60 sec between exercises · 2 min between rounds · 3 sets per round.

Why it's built this way

  • Every exercise is unique across the session — no repeats (72-hour rule).
  • Each round leads with one muscle and complements with different muscles — never three big primaries, never the same muscle doubled.
  • Whole body covered: legs, back, biceps, chest, triceps, shoulders, core.
  • Money slot is the DB Chest Press — loaded and safe, not a hinge. No RDL day one.
  • Neutral grip throughout (pushdown rope, neutral DB press) protects the 2020 wrist while still training everything.
  • Round 3 finishes on bodyweight (lunges, plank) — a smart, sustainable close for a first session back.

Summary — Every Rule This Session Taught

Consolidated from the corrections above. Each should be a hard check the eval harness runs against generated output.

  1. A round is one primary + complementing muscles. Never three large primaries in a round.
  2. Complements are DIFFERENT muscles that assist the primary (pull→biceps, press→triceps). Never double the same muscle in a round.
  3. Never all-legs in a round unless the user selected a leg workout.
  4. Full Body spreads the major muscles across rounds so the whole body is trained by the end.
  5. No exercise repeats in a session unless it's a burnout finisher (in-session 72-hour rule).
  6. The Money movement must be loaded AND appropriate — for a returning/beginner user, never a loaded hinge.
  7. Injury = MODIFY where possible, not BLOCK — pick neutral-grip / wrist-friendly variants rather than removing movements.
  8. Returning / first-day-back users get the Beginner pool and moderate intensity, independent of age.
  9. Every card is self-guiding: round flow, set count, rep/time targets, and rest intervals within and between rounds.

The meta-lesson. Every wrong draft above is a mistake an unconstrained model makes by default — the full-body spray, the heavy hinge, the repeated accessory, the doubled muscle. They look reasonable one at a time, which is exactly why they must be hard rules in code and explicit checks in the harness, not left to the prompt to remember.
