# dadbod-trainer

An open workout diary. Training with [Brian Andrews](https://www.instagram.com/brianandrewsfit/) (@brianandrewsfit), founder of [Define Fit](https://www.instagram.com/definefitapp/) (@definefitapp).

Live site: https://fahdi.github.io/dadbod-trainer/

## What this is

Each entry is a hand-written static page. Full workout sessions include the exercise card plus the coaching transcript that produced it: the drafts, Brian's corrections, and the rule each correction taught. Lighter entries (rest days, cardio, nutrition check-ins) get a shorter page without the exercise table.

## Structure

- `index.html` - the diary homepage, newest entry first
- `sessions/` - one page per diary entry
- `style.css` - the one shared stylesheet

No build step, no framework, no dependencies. Plain HTML and CSS, served directly by GitHub Pages.
